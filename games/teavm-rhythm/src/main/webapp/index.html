Scoring

Δt = t_press − t_note
b = 300 if |Δt| ≤ 50 ms, 200 if ≤ 100 ms, 100 if ≤ 150 ms, 0 if missed
score += base × min(4, 1 + ⌊combo / 10⌋)
combo ← combo + 1 on a hit, 0 on a miss

The multiplier uses the combo before the hit. combo/10 is integer division.

LIF autoplayer (B)

Four leaky integrate-and-fire neurons, one per lane, using math ported from src/main/java/com/fruitfly/brain/LIFRK4.java (RK4, 50 × 1 ms substeps per 50 ms tick). Each lane's next note sends its neuron one conductance pulse, and a spike is that lane's key press.

Lane names (antennal lobe, mushroom body, lateral horn, lobula) are display labels only. The lanes aren't wired to those brain regions or to the connectome.
