Scoring

Δt = t_press − t_note
b = 300 if |Δt| ≤ 50 ms, 200 if ≤ 100 ms, 100 if ≤ 150 ms, 0 if missed
score += base × min(4, 1 + ⌊combo / 10⌋)
combo ← combo + 1 on a hit, 0 on a miss

The multiplier uses the combo before the hit. combo/10 is integer division.

LIF autoplayer (B)

Four leaky integrate-and-fire neurons, one per lane, using math ported from src/main/java/com/fruitfly/brain/LIFRK4.java (RK4, 50 × 1 ms substeps per 50 ms tick). Each lane's next note sends its neuron one conductance pulse, and a spike is that lane's key press.

Lane names (antennal lobe, mushroom body, lateral horn, lobula) are display labels only. The lanes aren't wired to those brain regions.

Connectome autoplayer & assist (C)

C cycles: off → LIF autoplay → connectome autoplay → assist (LIF fly) → assist (connectome fly), between songs only. In connectome mode each lane's cue drives laneN.in, spikes travel through weighted, delayed synapses to laneN.out, and an output spike is the key press. In assist modes you play; the fly only presses for a note you haven't hit once it is 75–150 ms late, and the HUD counts hits by you vs by the fly.

The circuit is a TOY (toy_lane_circuit.xml, 12 neurons, 20 synapses, hand-written), not the Drosophila connectome. The 3D brain on the stage is a display-only toy layout echoing the AR screenshot's labels, not anatomy. ?connectome=URL loads another file in the same format.

Stage: a light backdrop with a procedural perspective floor (default). ?bg=ar uses the AR fly-brain screenshot (dimmed) instead; ?camera=1 tries a live camera backdrop and falls back to the screenshot. ?device=iphone12 forces the 390×844 layout.

Charts & audio

Play the sample JSON chart (?chart=charts/sample_chart.json). With a chart, song time is the audio position plus offset_ms, read every frame. Audio is ?audio=URL, else the chart's metadata.audio, else a click track the page synthesises at the chart's bpm. ?audio=none or an audio error falls back to the frame clock.
