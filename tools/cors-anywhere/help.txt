Private loopback CORS Anywhere (AxiomicCoreness)
================================================

Bind: 127.0.0.1 only (Cosmic Alignment — never 0.0.0.0).
This is NOT an open proxy. Origins must be on CORSANYWHERE_WHITELIST.
Do NOT use https://cors-anywhere.herokuapp.com/

Usage (prefix the target URL with this proxy base):

  /                 This help
  /iscorsneeded     Plain text "no" (no CORS headers)
  /<url>            Proxy <url> and attach CORS headers for a
                    whitelisted Origin (scheme optional; :443 => https)

Examples (with this server on http://127.0.0.1:8080):

  http://127.0.0.1:8080/https://example.com/
  http://127.0.0.1:8080/example.com
  http://127.0.0.1:8080/example.com:443

Required request header: Origin or X-Requested-With.
Cookies are stripped from proxied requests and responses.

Env:
  PORT                     listen port (default 8080)
  HOST / BIND_HOST         must be 127.0.0.1 or localhost (else FATAL)
  CORSANYWHERE_WHITELIST   comma-separated Origins (required non-empty)
  CORSANYWHERE_RATELIMIT   e.g. "50 1" = 50 requests per minute / origin

Separate from port380 harden-CORS (/healthz allowlist). Do not weaken it.
