# AKLT — Independent Research Notes

Sources: arXiv 2201.09307 (review), SciPost Phys. Core 7.4.078, arXiv 1906.12207
(Haldane gap + edge states), InspireHEP VBS review, arXiv 0901.4106 (entanglement
entropy), Stuttgart iMPS notes.

## 1. Hamiltonian

Two equivalent forms in the literature:

    H = Σ_k [ S_k · S_{k+1} + (1/3) (S_k · S_{k+1})^2 ]                  (A)

    H = Σ_k π_2(k, k+1)
      = Σ_k (1/6) [ (S_k · S_{k+1})^2 + 3 S_k · S_{k+1} + 2 ]            (B)

Each π_2(k,k+1) is the projector onto total pair spin S = 2. Source (B):
InspireHEP VBS review, Eq. 4.3. Source (A): arXiv 1906.12207 Eq. 11.

## 2. Frustration-free ground state

π_2 has eigenvalues {0, 1} and is positive semidefinite. Therefore H is
positive semidefinite. Any state annihilated by every π_2 is a zero-energy
eigenstate. The VBS state is such a state — constructed by taking each physical
spin-1 as the symmetric triplet of two auxiliary spin-1/2's, then pairing
auxiliary spins on adjacent sites into singlets. Source: arXiv 1906.12207
lines 18–32; InspireHEP lines 7–15.

Consequences:
- E_0 = 0 exactly (for any boundary condition, even N).
- Ground state is unique for periodic BC.
- Ground state is 4-fold degenerate for open BC (two free spin-1/2 edges →
  (1/2) ⊗ (1/2) = 0 ⊕ 1 → 4 states).

Sources: search result [12] lines 38–41 (periodic: 1; open: 4);
search result [1] lines 13–18 (edge states, Haldane gap).

## 3. MPS representation

Bond dimension χ = 2 (auxiliary spin-1/2). For a periodic chain of L sites:

    |MPS⟩ = tr( g_1 g_2 ... g_L ),
    (g_j)_{αβ} = Σ_m A_{αβ}(m) |m⟩_j

with three 2×2 matrices A^{+1}, A^0, A^{-1}. Source: InspireHEP review,
Eq. 4.5–4.6.

## 4. Transfer matrix and correlation length

Single-site transfer matrix T = Σ_s A^{s} ⊗ conj(A^{s}), 4×4. Source:
Stuttgart iMPS notes lines 6–8; PEPSKit issue #199 lines 18–22.

Eigenvalue structure: exactly one eigenvalue has |λ| = 1 (the singlet
normalization). The next-largest magnitude is |λ_2| = 1/3.

Bulk correlation length from MPS:

    ξ = -1 / ln|λ_2| = -1 / ln(1/3) = 1 / ln(3) ≈ 0.9102392266…

Published value: ξ = 1/ln(3). Source: arXiv 0901.4106; search result [9]
lines 7–8 and 13–14.

## 5. String order parameter

    Π^α_{i, i+r} = S^α_i · exp(iπ Σ_{j=i+1}^{i+r-1} S^α_j) · S^α_{i+r}

Exact value in the AKLT state, α = x, y, z:

    O_SO(AKLT) = -4/9

Independent of boundary condition and choice of boundary spins.
Source: SciPost Phys. Core 7.4.078, Eq. 7 and text below; search result [6]
lines 9–11.

Origin: Kennedy–Tasaki duality. Under U_KT = Π_{j<k} exp(iπ S^z_j S^x_k),
the AKLT Hamiltonian maps to a Hamiltonian with full Z2 × Z2 spontaneous
symmetry breaking. The string order parameter detects the corresponding
ferromagnetic order in the transformed frame. Source: arXiv 2201.09307
§5.1, lines 16–24.

## 6. Hidden Z2 × Z2 symmetry

Generated by π-rotations about the three principal axes:

    R^x = exp(iπ S^x),  R^y = exp(iπ S^y),  R^z = exp(iπ S^z)

Each R^α has order 2 on spin-1 (R^α squared = identity up to a phase), and
the group is Z2 × Z2. The Haldane phase is characterized by complete breaking
of the transformed Hamiltonian under this group. Source: arXiv 2201.09307
lines 19–21; SciPost lines 19–24.

## 7. Haldane gap (adjacent, not identical, model)

For the isotropic spin-1 Heisenberg chain H = Σ S_i · S_{i+1}:

    Δ ≈ 0.41049(2)

by DMRG on 22 sites. Source: OSTI search result [1] line 29–30.
The AKLT point is a special point in the bilinear-biquadratic phase diagram
where the gap is also nonzero and the ground state is exactly known. Not
asserted here — the exact AKLT gap is not among the values independently
verified in this note.
